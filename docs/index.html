What the extension does

The extension operates only on copilotstudio.microsoft.com. It sets the client preference AgenticAutomationsShellOptIn to false, reloads the page when required, and hides the “New Copilot Studio experience / Try now” promotion and “New experience” toggle.

🔒

Enforces classic

Automatically restores the classic experience when the new shell is selected.

🙈

Removes promotion

Hides the banner and toggle that invite makers to switch to the new experience.

🏢

Policy managed

Can be force-installed in Microsoft Edge so users cannot disable or remove it.

See it in action

The guard keeps Copilot Studio on the classic experience, removes the Try now promotion, and automatically restores the classic shell when a user reaches the new experience.

Enterprise deployment with Microsoft Intune

The recommended enterprise approach is to force-install the extension through Microsoft Edge policy. When deployed this way, installation is silent and users cannot disable or remove the extension.

Important prerequisite: Intune cannot deploy the ZIP file directly. For enterprise policy deployment, package the extension as a signed .crx and host it together with an update.xml manifest, or publish the extension through Microsoft Edge Add-ons and use its extension ID.

1. Package the extension as CRX

Open Microsoft Edge extensions.edge://extensions
Enable Developer mode.

Use the toggle in the Extensions page.

Click Pack extension.

Select the folder that contains manifest.json, content.js and the other extension files.

Leave the private key field empty the first time.

Edge creates both a signed .crx package and a .pem private key.

Keep the PEM file secure.

Use the same PEM file for every future version. Otherwise the extension ID changes and Edge treats the update as a different extension.

2. Get the final extension ID

After packing, load or install the signed extension and open:

edge://extensions

Copy the ID shown on the extension card. Do not rely on the ID of a previously unpacked build unless the same signing key is used.

3. Create the update manifest

Create a file named update.xml:

<?xml version="1.0" encoding="UTF-8"?>
<gupdate xmlns="http://www.google.com/update2/response" protocol="2.0">
  <app appid="YOUR_EXTENSION_ID">
    <updatecheck
      codebase="https://your-host/extensions/copilotstudio/copilot-studio-classic-extension.crx"
      version="1.1.0" />
  </app>
</gupdate>

The version in update.xml must match the version in manifest.json.

4. Host the CRX and update.xml

Place both files on an HTTPS endpoint reachable by all managed devices:

https://your-host/extensions/copilotstudio/copilot-studio-classic-extension.crx
https://your-host/extensions/copilotstudio/update.xml

Suitable hosting options include Azure Blob Storage / Static Website, Azure App Service, or an internal HTTPS web server. For enterprise production, use a controlled corporate endpoint.

5. Verify hosting before Intune configuration

  • Open the update.xml URL from a managed device and confirm it is reachable.
  • Open the .crx URL and confirm the package is reachable.
  • Ensure the URLs do not require interactive authentication.

6. Create the Intune configuration policy

Intune admin center path Devices → Windows → Configuration → Create → New policy
  • Platform: Windows 10 and later
  • Profile type: Settings catalog
  • Name example: Edge - Copilot Studio Classic Experience Guard

7. Add the Microsoft Edge extension policy

Click Add settings and search for:

Configure extension management settings

This maps to Edge's ExtensionSettings policy and is the preferred option for this solution.

8. Configure force installation

Use the final extension ID and the hosted update manifest URL:

{
  "YOUR_EXTENSION_ID": {
    "installation_mode": "force_installed",
    "update_url": "https://your-host/extensions/copilotstudio/update.xml",
    "override_update_url": true
  }
}

force_installed installs the extension silently and prevents users from disabling or removing it. override_update_url ensures Edge uses your self-hosted update source for later versions.

9. Assign the policy

  • Start with a pilot Entra ID group.
  • Test with a small number of Copilot Studio makers or admins.
  • Expand to a wider group only after validation.

10. Force an Intune sync

On the pilot Windows device:

Settings → Accounts → Access work or school → Connected organization → Info → Sync

Then restart Microsoft Edge.

11. Verify the policy on the endpoint

edge://policy
  • Click Reload policies.
  • Confirm ExtensionSettings is present.
  • Confirm the policy status is OK.

12. Verify the extension

edge://extensions

Confirm Copilot Studio Classic Experience Guard is installed and shown as managed by your organization. A force-installed extension should not expose a user-removable state.

13. Validate Copilot Studio behavior

Production

https://copilotstudio.microsoft.com/

Preview

https://copilotstudio.preview.microsoft.com/

In DevTools Console, verify:

localStorage.getItem("AgenticAutomationsShellOptIn")

Expected result:

"false"

Also confirm that:

  • The Try now promotion is hidden.
  • The New experience toggle is hidden.
  • If a user reaches the new experience, the extension restores the classic experience.

Updating the extension later

For version 1.2.0 or later:

  1. Update manifest.json to the new version.
  2. Repack using the same PEM private key.
  3. Replace the hosted .crx.
  4. Update the version in update.xml.
  5. Keep the extension ID and Intune policy unchanged.

Alternative: ExtensionInstallForcelist

Instead of ExtensionSettings, Intune can also use the Microsoft Edge policy Control which extensions are installed silently. 

YOUR_EXTENSION_ID;https://your-host/extensions/copilotstudio/update.xml

For this solution, ExtensionSettings is recommended because it gives explicit control over installation mode and update behavior.

Compatibility note: this is a managed workaround, not a native Copilot Studio tenant setting. It currently depends on the client-side preference AgenticAutomationsShellOptIn and current Copilot Studio UI structure. Revalidate the extension after significant Copilot Studio releases.
