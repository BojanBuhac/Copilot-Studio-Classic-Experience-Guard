What the extension does

The extension operates only on copilotstudio.microsoft.com. It sets the client preference AgenticAutomationsShellOptIn to false, reloads the page when required, and hides the “New Copilot Studio experience / Try now” promotion and “New experience” toggle.

🔒

Enforces classic

Automatically restores the classic experience when the new shell is selected.

🙈

Removes promotion

Hides the banner and toggle that invite makers to switch to the new experience.

🏢

Policy managed

Can be force-installed in Microsoft Edge so users cannot disable or remove it.

See it in action

The guard keeps Copilot Studio on the classic experience, removes the Try now promotion, and automatically restores the classic shell when a user reaches the new experience.

Enterprise deployment

For production, package and host the extension centrally, then deploy it through Microsoft Edge policy. A force-installed extension is installed silently and users cannot disable or remove it.

Package and host the extension.

Publish it in Microsoft Edge Add-ons for private organizational use, or self-host a signed .crx package and update manifest on an HTTPS endpoint reachable by managed devices.

Obtain the extension ID.

Use the ID assigned by the Edge Add-ons store, or the stable ID generated for your signed/self-hosted package.

Force-install through policy.

Use ExtensionInstallForcelist or the more granular ExtensionSettings policy.

Target a pilot group first.

Assign the policy to a small maker/admin group, validate Copilot Studio behavior, and then expand the assignment.

Validate on endpoints.

Open edge://policy and edge://extensions to confirm that the policy is applied and the extension is marked as installed by your organization.

Group Policy / ADMX

In Group Policy Editor go to Administrative Templates → Microsoft Edge → Extensions → Control which extensions are installed silently. Enable the policy and add the extension ID. For a self-hosted extension, append the update-manifest URL.

EXTENSION_ID;https://your-company.example/extensions/copilot-studio-classic/update.xml

Microsoft Intune / Edge policy

Create a Microsoft Edge configuration policy and configure ExtensionInstallForcelist. Alternatively, use ExtensionSettings for a single consolidated JSON policy.

{
  "YOUR_EXTENSION_ID": {
    "installation_mode": "force_installed",
    "update_url": "https://your-company.example/extensions/copilot-studio-classic/update.xml"
  }
}

Microsoft Edge management service

In the Microsoft 365 admin center, select the relevant Edge configuration profile, open the Extensions section, add the extension by ID, and set its installation policy to Force.

Important: this solution depends on Copilot Studio's current client preference AgenticAutomationsShellOptIn and current UI structure. Treat it as a managed compatibility control, not a Microsoft product setting. Validate it after significant Copilot Studio releases.
